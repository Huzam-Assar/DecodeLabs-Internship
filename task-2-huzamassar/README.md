# Atlas-Core

A minimal DevOps demo app used to practice Git version control: init, add, commit,
branch, merge, and push to GitHub.

## Description

Small command-line greeter app built to practice the core Git workflow required
for Project 2 (Version Control with Git) of the DecodeLabs DevOps Industrial
Training Kit, Batch 2026. History and traceability matter more than the app
itself — every change below is its own commit.

## Installation

```bash
git clone https://github.com/<your-username>/atlas-core.git
cd atlas-core
```

No dependencies — pure Python 3 standard library.

## Usage

```bash
python3 app.py
```
